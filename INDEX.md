## 🚀 Quick Start (TL;DR)

### Terminal 1 - Backend

```bash
cd backend
npm install
npm run dev
# Backend running on http://localhost:5000
```

### Terminal 2 - Frontend

```bash
cd frontend
npm install
npm run dev
# Frontend running on http://localhost:3000
```

### Open Browser

```
http://localhost:3000
```

**That's it!** See [SETUP.md](./SETUP.md) for detailed instructions.
